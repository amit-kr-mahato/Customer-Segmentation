### Customer Segmentation Using Machine Learning

Developed a machine learning-based customer segmentation system to group customers based on their purchasing behavior, demographics, and spending patterns. Applied data preprocessing, exploratory data analysis, feature engineering, and clustering techniques such as **K-Means** to identify distinct customer segments. The insights can help businesses design targeted marketing campaigns, improve customer engagement, and make data-driven business decisions.

**Technologies:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Jupyter Notebook and pandas
